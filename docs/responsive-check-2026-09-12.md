# PC·휴대폰 화면 점검

대상: https://lawtest.or.kr/ · 2026-09-12

운영 사이트를 데스크톱 브라우저의 화면 크기 조정 기능으로 검사했다. 수정 사항은 로컬 미리보기에서 재검증했다. 실제 휴대폰 하드웨어, iOS Safari, 삼성 인터넷의 독립 검증은 포함하지 않는다.

## 수정한 문제

1. **320px 개인정보 안내문:** 최소 너비280px과 중첩 여백 때문에 문서가329px까지 늘어났다. 고정 최소 너비를 해제하고 휴대폰에서 아이콘·본문을 세로로 배치했다. 재검사에서 화면 밖 텍스트가 없었다.
2. **휴대폰 가로 메뉴:** 390px 높이 화면에서 메뉴 하단이462px까지 내려갔다. 사용 가능한 화면 높이에 맞춰 메뉴 내부 스크롤을 제공하고, 메뉴를 열었을 때 결과 버튼을 숨겼다. 수정 후 메뉴 하단378px, 마지막 항목 이동·닫기·화면 전환 정상.

## 함께 반영한 내용

운영자가 정소원·박단비도 수상자임을 확인하여 두 논문을 통합했다. 수상자 학술 논문은 총6편이며 ‘관련 연구 성과’ 구역은 제거했다.

## 학교 번호·점수 표 후속 확인

- 주요 학교 12개교와 전체 학교 71개교에 연속 번호를 표시했다. 새 학교 3개교와 경찰대학 명칭을 확인했다.
- `universities.html`을 320, 390, 720, 768, 900, 1100, 1440px 너비에서 확인했다. 학교 카드·이름의 넘침과 문서 전체 가로 넘침이 없었다. 좁은 화면의 점수 표는 표 내부 가로 스크롤로 읽는다.
- PC에서 주요 학교 강조 카드·전체 학교 카드·점수 표, 휴대폰에서 학교 카드 배치를 시각 확인했다.
- 제7·8회는 회차·시상일·출처가 각각 하나의 셀로 묶이며 이름과 점수는 수상자별로 대응한다. 평균 열·제목·검색 설명은 삭제했다.
- 논문 6편은 유지하고 하단 수상 이력 설명만 삭제했다.
- 정적 검사: 16개 페이지, 703개 로컬 참조 통과. 회차 8개 그룹, 대상 점수, 학교 번호 1–71 및 중복 여부를 별도 대조했다.
