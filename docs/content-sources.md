# 공개 내용과 확인 자료

확인일: 2026-09-12

- 제8회 시상식(2026-09-12 토요일 14:00, 변호사회관 5층 정의실), 대상 이름·상명: 운영자 확인.
- 정헌욱 69점, 김영진 67점: 운영자가 공개를 허락한 채점표와 문항별 점수 합계 대조. 100문항·각 1점. 두 대상은 동점·공동 1위가 아니다.
- 김영진 학과: 시상식 참가신청서의 ‘KAIST 산업및시스템공학과’ 표기 반영.
- 제8회 사진: `data/site.json`의 `round8.photo`는 null. 사진 전달 후 `assets/images/`에 저장하고 이 값에 경로를 입력한다. 가상 이미지나 다른 회차 사진을 사용하지 않았다.
- 제8회 참가 후기: 운영자가 참고를 지시한 시상식 참가신청서에서 발췌. 접수 자료의 공개 동의가 ‘아니오’이거나 후기에서 공개를 원치 않는다고 밝힌 답변은 제외하고 중복을 제거했다. 이름은 마스킹하고 개인적 상황은 제외했다. 후기에 관한 별도 동의 문항은 없으며 접수 동의는 성명·학교 등의 언론·인터넷 공개에 관한 문항이다. 홈페이지 반영은 운영자의 이번 요청 범위에 따른다.
- 제8회 소속 학교: 접수·결과 자료를 합친 학교명 목록. 실제 응시·수상 학교 수 또는 응시자 수로 해석하지 않는다.
- 제1~7회 결과: `data/site.json` 각 행의 법률저널 보도. 제2회 전체평균은 기사에서 확인되지 않아 비웠다. 제7회 최고점 85점·또 다른 대상 81점을 추가했다. 기사와 기존 홈페이지의 제7회 시상식 시각이 달라 날짜만 표시한다.
- 제8회 개최 기사: [법률저널 2026-07-23](https://www.lec.co.kr/news/articleView.html?idxno=752452), [피앤피뉴스 2026-07-27](https://gosiweek.com/article/1065596232175960). 제8회 결과 기사로 분류하지 않는다.
- 논문: `data/publications.json`에 KCI·DOI를 기록했다. 실제 게재 6편 중 수상자 연결을 확인한 4편과 별도 관련 연구 2편을 구분했다. 작성 중·투고·게재예정 편수는 개별 서지가 확인되지 않아 확정 게재 목록에 포함하지 않았다.
- 기관명: 운영자가 확정한 ‘대한변협법률구조재단 이사장상’을 기준으로 정리했다.

## 아직 비워 둔 정보

제9회 일정·요강, 제2회 학습법 공모전 확정 일정·양식, 개인정보 항목별 실제 보관 기간, 새 시험·감독 서비스 등은 확인 자료가 없어 임의로 정하지 않았다. `data/site.json`의 `unconfirmed`와 홈페이지 안내의 빈칸을 실제 운영 기준이 정해진 뒤 채워야 한다.

원본 신청서·채점표·연락처·공개 거부 응답은 이 저장소에 포함하지 않는다.
