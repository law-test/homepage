# 법학경시대회 홈페이지

[lawtest.or.kr](https://lawtest.or.kr/)에서 서비스하는 정적 홈페이지입니다. 공통 메뉴·회차 정보·논문 목록을 한 곳에서 관리하고 HTML을 생성합니다. 빌드는 Python 3 표준 라이브러리만 사용합니다.

## 내용 수정

- `data/site.json`: 제9회 확정 일정·요강, 제8회 시상식·수상자·점수, 제1~7회 기록, 공모전 요강과 미확정 항목.
- `data/publications.json`: 학생 공동연구·수상자 논문 서지와 KCI·DOI.
- `content/*.html`: 각 페이지 본문. 생성된 루트 HTML을 직접 수정하지 않습니다.
- `templates/layout.html`: 공통 메뉴·배너·푸터·검색 및 공유 정보.
- `assets/css/updates.css`, `assets/js/site.js`: 공통 화면과 메뉴·사진 확대 동작.
- `docs/content-sources.md`: 확인 자료와 미확정 항목.

## 빌드와 확인

저장소 루트에서 실행합니다.

```sh
python -X utf8 scripts/build_site.py
python -X utf8 scripts/check_site.py
node --check assets/js/site.js
python -m http.server 8765 --bind 127.0.0.1
```

마지막 명령은 로컬 확인용 서버입니다. `http://127.0.0.1:8765/`에서 데스크톱·모바일 메뉴, 공지·FAQ 바로가기, 모든 본문·정답의 기본 노출과 사진 확대를 확인합니다. 정적 검사는 내부 링크·앵커·공통 메뉴·제목·구조화 데이터·핵심 수상 결과를 검사합니다. 실제 시험 시스템이나 외부 결제는 검사하지 않습니다.

생성된 루트 HTML 18개와 `sitemap.xml`도 함께 커밋합니다. 기존 GitHub Pages 배포 경로와 `CNAME`을 유지합니다. `.nojekyll`은 생성된 파일을 그대로 배포하도록 합니다.

## 제8회 사진 추가

확정 사진을 `assets/images/`에 저장하고 `data/site.json`의 `round8.photo`에 `/assets/images/파일명.jpg` 형식으로 경로를 입력한 뒤 다시 빌드합니다. 사진이 없는 동안에는 빈 사진 영역과 안내가 표시됩니다. 다른 회차의 사진으로 대신하지 않습니다.

## 확인이 필요한 정보

제9회 접수·응시 기간은 2026.09.21.–11.30.이며, 최신 확정 기준을 공지·응시 안내·FAQ와 포스터에 반영했습니다. 홈에는 진행 중인 제9회, 수상 기록과 언론보도를 안내합니다. 논문 목록은 대회 기록과 수상자 공동체 활동 페이지에 둡니다. 제2회 전국 자기주도 학습법 공모전은 2026.09.26. 마감하여 기록으로 보관합니다. 접수 상태 표시는 한국 시간 시작·마감 시각에 따라 자동으로 바뀝니다. 제9회 상품의 현행 결제 금액 49,500원은 2026.10.04. 확인값입니다. 재응시자 환급·취소·환불·동점자 처리 등 별도로 정리되지 않은 세부 운영 기준은 임의로 추가하지 않습니다. 점수는 공개 허락된 값만 사용하며 원본 신청서·채점표·연락처는 저장소에 올리지 않습니다.

## 스크롤로 이어 읽기 · 2026-10-01

- `records.html`은 회차 기록과 `universities`, `achievements`, `voices`, `media` 본문을 빌드 시 통합합니다. 기존 개별 주소는 유지합니다. 각 본문의 수정이 통합 페이지에도 반영됩니다.
- 대회 기록 목차는 같은 페이지의 앵커로 이동하며, 언론보도 회차 ID는 `press-round-N`으로 구분합니다.
- 공모전 3개 페이지 모두 원 공고와 제1회 수상작을 포함합니다. 응시 안내에는 FAQ 전체를 포함합니다.
- 원본의 `details`·`summary`는 빌드 시 일반 본문·제목으로 변환합니다. 자바스크립트가 꺼져도 답변·해설·축사·연구 내용이 보입니다. FAQ 구조화 데이터는 변환 전에 생성합니다.
- 모바일 주요 메뉴도 항상 표시합니다. 사진 확대·외부 기사 원문·파일 다운로드는 별도 동작으로 유지합니다.

참가 후기는 상단 주요 메뉴에서 바로 이동하며, 메인에서는 기존 후기 3건을 미리 보여 줍니다. 수상자 공동체 활동은 하랑재·법학 서적·학술 논문·학습법 공모전·연구·사회 기여 순서로 01~06 번호를 표시합니다.

## 접수 안내 연결 · 2026-10-04

- 상단·모바일·푸터 메뉴의 `참가 신청`, 메인 접수 버튼·카드, 공통 배너·고정 버튼, 공지·FAQ·공모전 기록의 참가 신청 링크는 스마트스토어 제9회 상품으로 바로 연결합니다. 안내 페이지를 중간에 거치지 않습니다.
- 결제는 스마트스토어 제9회 상품, 결제 후 참가정보 작성은 기존 네이버폼으로 연결합니다. 두 외부 주소와 결제 금액은 `data/site.json`의 `round9`에서 관리합니다. 참가 신청 링크는 `payment_url`을 사용합니다. 응시 안내의 단계별 버튼은 `application_actions()`로 생성하며 상세 규정·과목·준비물은 기존 `/guide.html`과 해당 앵커에서 확인할 수 있습니다.
- `mylawtest.com`은 스마트스토어 홈으로 연결되는 기존 접수 주소입니다. 직접 결제 버튼은 제9회 상품 주소를 씁니다. `lawtest.co.kr`은 별도로 관리하는 아임웹 사이트로, 이 저장소에서는 수정하거나 역방향 링크를 추가하지 않습니다. 해당 사이트의 안내도 최신 공식 홈페이지로 연결하는 방향으로 관리합니다.
- 1~3일 준비 제안은 학습 순서이며 수상·성적·응시 가능 시점의 보장이 아닙니다. 이메일 안내 기간과 구분합니다. 외부 결제나 폼 제출 여부를 홈페이지에서 자동 판정하지 않습니다.

## 공식 안내 중심의 구성 · 2026-10-04

- 공식 홈페이지는 대회명·일정·요강·접수 절차·예시 자료·수상 기록을 중심으로 안내합니다. 홍보 구호와 반복적인 가입 유도 문구는 메인에 사용하지 않습니다.
- 메인에서는 제9회 개요 다음에 공지사항을 보여 주며, 참가 신청은 스마트스토어 제9회 상품으로 바로 연결합니다. 제7회 고교생 수상 사실은 해당 회차 기록에서, 1~3일 학습 순서 예시는 응시 준비 절에서 확인할 수 있습니다.
