# 법학경시대회 홈페이지

[lawtest.or.kr](https://lawtest.or.kr/)에서 서비스하는 정적 홈페이지입니다. 공통 메뉴·회차 정보·논문 목록을 한 곳에서 관리하고 HTML을 생성합니다. 빌드는 Python 3 표준 라이브러리만 사용합니다.

## 내용 수정

- `data/site.json`: 제9회 확정 일정·요강, 제8회 시상식·수상자·점수, 제1~7회 기록, 공모전 요강과 미확정 항목.
- `data/publications.json`: 학생 공동연구·수상자 논문 서지와 KCI·DOI.
- `content/*.html`: 각 페이지 본문. 생성된 루트 HTML을 직접 수정하지 않습니다.
- `templates/layout.html`: 공통 메뉴·배너·푸터·검색 및 공유 정보.
- `assets/css/institutional.css`: 공통 기관형 디자인과 모바일 화면.
- `assets/css/updates.css`, `assets/js/site.js`: 기존 본문 스타일과 메뉴·사진 확대 동작.
- `docs/content-sources.md`: 확인 자료와 미확정 항목.

## 빌드와 확인

저장소 루트에서 실행합니다.

```sh
python -X utf8 scripts/build_site.py
python -X utf8 scripts/check_site.py
node --check assets/js/site.js
python -m http.server 8765 --bind 127.0.0.1
```

마지막 명령은 로컬 확인용 서버입니다. `http://127.0.0.1:8765/`에서 데스크톱·모바일 메뉴, 공지·FAQ 바로가기, 모든 본문·정답의 기본 노출과 사진 확대를 확인합니다. 정적 검사는 내부 링크·앵커·공통 메뉴·제목·구조화 데이터·핵심 수상 결과를 검사합니다. 실제 시험 시스템이나 외부 결제는 검사하지 않습니다.

생성된 루트 HTML 18개와 `sitemap.xml`도 함께 커밋합니다. 기존 GitHub Pages 배포 경로와 `CNAME`을 유지합니다. `.nojekyll`은 생성된 파일을 그대로 배포하도록 합니다.

## 제8회 사진 추가

확정 사진을 `assets/images/`에 저장하고 `data/site.json`의 `round8.photo`에 `/assets/images/파일명.jpg` 형식으로 경로를 입력한 뒤 다시 빌드합니다. 사진이 없는 동안에는 빈 사진 영역과 안내가 표시됩니다. 다른 회차의 사진으로 대신하지 않습니다.

## 확인이 필요한 정보

제9회 접수·응시 기간은 2026.09.21.–11.30.이며, 최신 확정 기준을 공지·응시 안내·FAQ와 포스터에 반영했습니다. 홈에는 진행 중인 제9회, 수상 기록과 언론보도를 안내합니다. 논문 목록은 대회 기록과 수상자 공동체 활동 페이지에 둡니다. 제2회 전국 자기주도 학습법 공모전은 2026.09.26. 마감하여 기록으로 보관합니다. 접수 상태 표시는 한국 시간 시작·마감 시각에 따라 자동으로 바뀝니다. 가격은 홈페이지 본문·버튼·접근성 문구·공개 데이터에 표시하지 않고, 스마트스토어에서 확인하도록 합니다. 재응시자 환급·취소·환불·동점자 처리 등 별도로 정리되지 않은 세부 운영 기준은 임의로 추가하지 않습니다. 점수는 공개 허락된 값만 사용하며 원본 신청서·채점표·연락처는 저장소에 올리지 않습니다.

## 스크롤로 이어 읽기 · 2026-10-01

- `records.html`은 회차 기록과 `universities`, `achievements`, `voices`, `media` 본문을 빌드 시 통합합니다. 기존 개별 주소는 유지합니다. 각 본문의 수정이 통합 페이지에도 반영됩니다.
- 대회 기록 목차는 같은 페이지의 앵커로 이동하며, 언론보도 회차 ID는 `press-round-N`으로 구분합니다.
- 공모전 3개 페이지 모두 원 공고와 제1회 수상작을 포함합니다. 응시 안내에는 FAQ 전체를 포함합니다.
- 원본의 `details`·`summary`는 빌드 시 일반 본문·제목으로 변환합니다. 자바스크립트가 꺼져도 답변·해설·축사·연구 내용이 보입니다. FAQ 구조화 데이터는 변환 전에 생성합니다.
- 모바일 주요 메뉴도 항상 표시합니다. 사진 확대·외부 기사 원문·파일 다운로드는 별도 동작으로 유지합니다.

참가 후기는 상단 주요 메뉴에서 바로 이동하며, 메인에서는 기존 후기 3건을 미리 보여 줍니다. 수상자 공동체 활동은 하랑재·법학 서적·학술 논문·학습법 공모전·연구·사회 기여 순서로 01~06 번호를 표시합니다.

## 참가 안내 중심의 구성 · 2026-10-07

- LCT 참고 사이트의 차분한 기관형 구성을 참고하여 흰색·네이비·실제 시상식 사진과 간결한 문체를 사용합니다.
- 메인은 대회 소개 → 참가 경험 → 실제 후기 → 시상 기록 → 수상자 공동체 → 소식 → 참가 안내 순서입니다. 메인에 논문을 넣지 않습니다.
- 상단 메뉴와 홈의 참가 안내는 `/guide.html`로 연결합니다. 안내 하단에서 스마트스토어 제9회 상품 → 네이버폼 신청서 → 이메일 안내 → 사전 테스트로 이어집니다.
- 홈페이지에 가격을 표시하지 않습니다. 기존 반복 배너·떠다니는 결제 버튼은 제거했습니다.
- 광고 측정의 동의·거부와 철회 기능은 유지하며, 선택 영역은 화면을 가리지 않는 하단 영역에 둡니다.
- 자료·후기·FAQ는 스크롤로 읽습니다. 기존 URL과 주요 앵커를 유지합니다.
- 가격, 환불조건, 판매옵션은 홈페이지가 결정하지 않습니다. 기존 스마트스토어 설정과 공식 운영 안내를 따릅니다.

## 자기학습 게임 · 2026-10-10

- `/standard-game.html`의 도전 판례왕!·도전 조문왕!은 민법위키의 동일한 게임 코어·공개 문항은행·한글 PDF 도구를 사용합니다. 법학경시대회의 공통 헤더·로고·Pretendard와 네이비·금색을 재사용하며, 전용 `assets/lawtest-game.css`로 화면을 맞춥니다. 홈과 참가 안내에서 연결하며 공통 메뉴에 학습게임을 표시합니다.
- 600초 동안 헌법 3·민법 4·형법 3문항을 출제합니다. 두 게임의 진급은 별도로 저장합니다. 판례는 발간 누적 급수 50/150/300/500/1000/1800, 조문은 별도 학습단계 50/150/300/400/496을 사용합니다.
- 합격증과 만점 왕상장은 민법위키 명의의 학습용 PDF입니다. 공식 대회 점수·수상 결과·위원장상을 발급하지 않습니다. 이름과 생년은 PDF 생성 중에만 사용하며 저장하거나 서버로 전송하지 않습니다.
- 게임 기록은 각 사이트의 브라우저 저장소에 있습니다. `lawtest.or.kr`와 `lawinus.org`의 급수는 자동으로 공유되지 않습니다. 게임 코어·문항·PDF 자산은 그대로 유지하며, 공용 화면 제어는 메타설명을 정리한 최신 위키 스크립트와 같은 바이트로 동기화합니다. 게임과 홈·참가 안내의 장문 급수·출처 설명을 제거하고 실제 조건과 동작을 간단히 표시합니다.
- 게임은 공통 문서 템플릿의 빌드 대상에 넣지 않고 완성된 독립 페이지를 보존합니다. 사이트 검사에는 독립 게임 페이지의 별도 진입점과 내부 링크를 검사하도록 반영했습니다.
